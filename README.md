# CineSlice

A native iPhone video editor built like a vintage film editing table (a Moviola). You arrange
clips, trim them, line them up against a reference song, ride the volume, and export a 9:16 (or
4:5 / 16:9) video for Instagram. Footage is never modified; every edit is undoable.

The folder and Xcode project are still named **PocketInstrument** (the working title); the app
the user sees is **CineSlice**. `CLAUDE.md` holds the original product brief and rules.

> **Status (2026-11-18):** Phases 0–4 and most of Phase 5 are done and tested on the Simulator and
> on an iPhone 17 Pro. 64 core tests, 15 media-pipeline tests and 4 UI tests pass. Next: the app
> icon (three concepts in `DesignReferences/AppIcon concepts/`), a privacy manifest, first-run
> hints, TestFlight, then a VoiceOver pass last.

## Tech
- Swift 5 / SwiftUI, iOS 17+, iPhone only, portrait.
- AVFoundation (`AVMutableComposition`, `AVVideoComposition`, `AVAudioMix`, `AVPlayer`,
  `AVAssetExportSession`), PhotosUI, Accelerate (waveforms), Core Haptics via a small `Haptics` helper.
- No third-party dependencies, no server, no accounts. Everything is local.
- The Xcode project is generated by **XcodeGen** from `project.yml`. Don't regenerate casually:
  it drops the signing team and Xcode's upgrade settings. If you add a file, regenerate and then
  restore those settings (or add the file to the project in Xcode).
- Style: `swift-format` (`.swift-format`, 4 spaces, 120 columns), linted on every build.

## How the app is organised
**Data on disk.** `Application Support/Projects/<project-id>/` holds `project.json`, `Media/`
(the project's own copies of imported clips and music), `Exports/` (rendered videos and sync
files) and `Cache/` (waveforms). Saves are atomic and debounced (and also happen on backgrounding).

**One rule for edits.** Every change to `Project` is an `EditingCommand` (`actionName` +
`apply(to: inout Project)`), run through `WorkspaceModel.perform(_:)`, which puts it on the undo
stack, saves, and refreshes playback. Views never mutate the project directly. Drags show a live
draft and commit one command (one undo step) when the finger lifts.

Commands: AddClips, MoveClip, RemoveClip, DuplicateClip, TrimClip, SetFraming, SetCrop,
RenameProject, SetExportSettings, SetOrientation, SetReferenceAudio, SetMusicOffset,
SetMusicLock, SetClipVolume, SetMusicVolume, SetLoop, WriteAutomation, TrimAutomation,
EditCurvePoint, ClearAutomation.

**Preview = export.** `CompositionBuilder.build` turns a `Project` into the AV composition, video
composition (framing, crop, orientation, feed cut) and audio mix (levels and automation). Preview
and `ExportService` both call it, so what plays is what renders.

**Time.** Stored times are `MediaTime` (rational). Clip ranges are in *source* time; the sequence,
music offset and loop are in *composition* time; clip volume curves are in source time so they
travel with the clip. `SequenceMap` converts between them.

## Features
- **Library:** a sage-enamel table viewer; projects run below as a film strip, newest first.
  Create, rename, delete. **Storage** sheet: space per project (footage / renders / cache),
  clear renders, cache and temp files; a banner past 10 GB. Launch intro: brushed shutters with
  the CineSlice plate open on the library (tap to skip; fades with Reduce Motion).
- **Workspace** (one screen, three states: Arrange, Trim, Mix; Release is a sheet):
  - Viewer in a cast metal housing; outside the picture is a machined gate plate whose aperture
    springs between 9:16 and 16:9, with engraved rulers and the feed's 4:5 lines. **Watch** is
    full screen; tap the left/right edge to mark In/Out on the playing clip, double-tap the middle to clear.
  - **Jog/shuttle wheel** (horizontal knurled drum): jogs frames near where you touch, shuttles
    ¼×–4× either way when pushed out, stops on release.
  - **Arrange:** clip tiles (tap select, long-press drag reorder), full-width scrub lane with the
    music waveform, cuts and loop bracket, lane zoom, Fill/Fit, duplicate, delete, **Crop** (a
    per-clip push-in up to 4×, drawn and dragged/pinched over the picture).
  - **Trim:** whole-source filmstrip, In/Out handles and keys, zoom to the clip, music under it.
  - **Mix:** one reference song (Files, a video's sound, or a demo click track), slide/nudge it
    against the picture and lock it; per-clip and music faders; Write records fader rides as
    automation (Touch mode); Edit draws/moves/adds/deletes curve points by finger.
  - Loop a region, the selected clip or everything.
- **Release:** frame (Reels 9:16 or Feed 4:5 for vertical edits; 16:9 when horizontal), sound
  (Silent default with music / clip audio only / clip + music), H.264 MP4 1080p 30 fps, progress
  and cancel, Save to Photos, Share, **Instagram handoff** (where the song starts, three steps,
  Open Instagram on the saved video) and a `.sync.json` sidecar. Apps can't attach Instagram's
  licensed music, so the user lines the song up by hand there.

## Design system
Palette (only these, plus two vintage accents): Obsidian `#151816`, Instrument `#30372F`,
Olive `#56623B`, Signal `#D0DB65` (the lit/active colour), Aluminum `#BFC1B4`, Ivory `#ECE9DD`;
accents Brass `#B59A62` (name plates) and Enamel `#8A9774` (the library machine).
Materials: brushed olive graphite chassis, brushed aluminum plates, spun-metal round keys,
recessed wells, grain. Reusable pieces in `Design/Components.swift`: `KeyCap` /
`.instrument(...)` keys, `.round(...)` keys, `JogDial`, `Fader`, `Chassis`, `PanelSection`,
`EngravedLabel`, `TitlePlate`, `OptionKeyStyle`, `SegmentMeter`, `LED`, `GlassChip`, `Screw`,
`BrushedMetal`, `Grain`, `.recessed()`. Rules: every control works (no decorative buttons),
44 pt touch targets, haptic detents, Reduce Motion respected, mono type for technical labels.

## Build and test
```bash
# Core logic (no simulator needed)
cd Packages/EditCore && swift test
# Everything, in the Simulator
xcodebuild test -project PocketInstrument.xcodeproj -scheme PocketInstrument \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
# Lint / format
xcrun swift-format lint -r PocketInstrument PocketInstrumentTests PocketInstrumentUITests Packages
```
On a device, pass your team: `DEVELOPMENT_TEAM=<team id>` and keep the phone unlocked (playback
tests skip when the app isn't in the foreground). UI tests launch with `-skipIntro`.

## Adding a feature: conventions
- Model change → `EditCore` (Codable with `decodeIfPresent` defaults so old projects still open),
  a new `EditingCommand`, and a unit test.
- Anything that renders → `CompositionBuilder`, so preview and export agree; add a pipeline test
  that exports and checks the file.
- UI state and edit entry points → `WorkspaceModel`; views stay thin.
- Match the existing comment style (a short doc comment on each type saying what it is for),
  keep the palette, and avoid new files where an existing one fits (XcodeGen, see above).

## Known gaps
- No app icon in the build yet; no privacy manifest; no TestFlight setup yet.
- VoiceOver works on the main controls but hasn't had a full pass.
- Export uses `AVAssetExportSession.exportAsynchronously` (deprecated on iOS 18, still works).
- HDR sources export as SDR H.264.
- "Open Instagram" uses Instagram's undocumented `instagram://library?LocalIdentifier=` link;
  it falls back to just opening Instagram.
